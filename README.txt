# LUXORA Fashion Accessories Store

A responsive e-commerce front-end made with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure
- `style.css` — premium responsive design
- `script.js` — products, filters, cart, wishlist, modal, checkout demo and localStorage

## Run
Open `index.html` in Chrome/Edge/Firefox.

No server or build tool is required.

## Notes
- Product photography uses remote Unsplash image URLs. Replace these URLs in `script.js` with your own product images when ready.
- Checkout and login are demo front-end interactions; connect a real backend/payment gateway before accepting real orders.
